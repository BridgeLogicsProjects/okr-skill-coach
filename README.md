---

## What This Skill Does

Most OKR processes fail at the same places: objectives that describe activity instead of ambition, key results that measure what was shipped instead of what changed, and goals written without the people who have to execute them.

This skill fixes that. It coaches users through:

- Writing OKRs from scratch with the right questions in the right order
- Stress-testing any existing OKR set before it gets locked in
- Auditing the difference between outputs and outcomes
- Setting a check-in rhythm that keeps OKRs alive through the cycle
- Connecting strategy to execution so goals are not just aspirational

**The core principle: OKRs are not a template. They are a skill — built the same way quality assurance is built into a product. From the start, not bolted on at the end.**
